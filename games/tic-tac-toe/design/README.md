# Tic Tac Toe Design Reference 🎮

## Visual Source of Truth

The image file `game-ui-reference.png` stored in this folder is the primary visual source of truth for the Tic Tac Toe user interface.

## Design Language Specifications

When implementing the Tic Tac Toe UI in future phases, adhere strictly to these principles:

- **Base Theme**: Dark navy and deep blue layered background with subtle grid illumination.
- **Accents & UI Colors**: Bright arcade colors (vibrant cyan, neon amber/yellow, electric coral pink).
- **Control Styling**: Chunky arcade-style UI elements, tactile bevels, rounded/soft rectangular buttons with glossy finish and solid drop shadows.
- **Typography**: Bold, punchy, high-legibility arcade typography.
- **HUD (Heads-Up Display)**: Compact, clear header displaying:
  - Player 1 vs Player 2 score counter
  - Current turn banner with active player highlight
  - Round indicator (`ROUND: 05 / 09`)
  - Turn timer countdown badge
- **Action Buttons**: Chunky pill / soft-rectangle action controls ("NEW GAME", "RESET ROUND", "SETTINGS").
- **Aesthetic Direction**: Retro-modern casual gaming arcade. **Do not redesign into a generic corporate SaaS dashboard.**
